    Editor help
    Open the topic you need.
    
      
    
        
    Start an edit and check what changed
    Paste or type in Your text, or choose Try an example. Results update as you work. Choose Changes to see removals crossed out and additions underlined. Dots mark spaces and ↵ marks a line break. Choose Text to read the finished version.
    Use Keep my line breaks for addresses, poems and other text where each line matters. Fenced code keeps its formatting during cleanup.
    
        
    Open, copy, download and undo
    Open file reads UTF-8 plain text, including TXT, Markdown, CSV and TSV. Copy result copies your edited text. If your browser blocks copying, the editor selects the result for your usual Copy command. Download saves a UTF-8 text file.
    After clearing your text, opening a file or loading an example, Undo brings back the previous text. Type again to start a new edit.
    
        
    Read counts and set a limit
    Under Text counts, choose Your text or Result. Set a limit lets you enter a word or character maximum. The meter and message show how much room you have. Edit limit lets you change or remove it.
    Lines include blank lines. Reading time assumes 200 words per minute. Character counts group visible emoji and accented letters when your browser supports it.
    
        
    Find tools, combine them and save steps
    Open More tools, search by name or task, and choose Use to apply a single tool. To combine tools, open Edit steps. Choose Add, then use Up, Down or Remove to adjust the order. The editor applies the first step first.
    Save these steps gives the sequence a name. Open Saved steps to use it again, delete it or undo a deletion.
    
        
    Move saved steps to another browser
    Open Saved steps → Move steps to another browser. Select a sequence and choose Download steps file. In the other browser, choose Open steps file, review its settings and save it. Choose Use when you want to apply it.
    The settings file includes the sequence name, tools and any saved find-and-replace words. Your working text stays in the tab.
    
        
    Use the keyboard, a phone or dark mode
    Press Tab to reach controls. The first link skips straight to the editor or guide. Use Enter to follow links, Space to toggle a checkbox and Esc to close a dialog. On a narrow screen, View result and Back to my text move between the two areas.
    The appearance button in the top bar switches light and dark mode. Returning from this guide in the same tab keeps your text and editor settings.
    
        
    Privacy, large pastes and offline use
    Your text is processed in this tab. Reloading starts a fresh draft. Saved steps and appearance stay in this browser. To use the app offline, open index.html from the complete downloaded folder.
    You can paste up to 100,000 text units at once. Most letters count as one unit, and some emoji use several. You can combine up to 16 steps. Each find or replacement can use 1,000 units, and a result can reach 300,000. If an edit is too long to highlight, choose Text to read or copy the full result.
